# School LMS

A Phase 1 foundation for a school and college learning management system. The npm workspace contains a Next.js web app, a NestJS REST API, and a shared TypeScript package.

```powershell
npm ci
npm run dev
```

- Web app: http://127.0.0.1:3000
- API health: http://127.0.0.1:3001/api/health

See [local setup](docs/setup.md) for commands and environment file locations, and [architecture](docs/architecture.md) for the workspace and institution deployment model.
